# echo-path

echo-path is a monorepo containing all components of the project in a single Git
repository.

## Structure

| Path                | Description                                        |
| ------------------- | -------------------------------------------------- |
| `mobile-app/`       | Mobile client application.                          |
| `smart-door-infra/` | Infrastructure and deployment for the smart door.  |
| `backend/`          | Backend services and APIs.                          |

> Application code has not been added yet — this repository currently only
> defines the project structure.
